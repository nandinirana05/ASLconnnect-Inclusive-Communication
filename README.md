# ASLconnnect-Inclusive-Communication
ASLConnect is a C++ application that promotes inclusive communication by helping users learn American Sign Language through interactive lessons and quizzes. It applies DSA concepts like arrays, hash tables, stacks, queues, trees, and graphs to manage learning content and progress efficiently.
